## What was built

### 1. Reusable 3D engine (`engine/`, `utils/`)
Three.js r160, vendored locally (no runtime CDN). `mountWorld(container, worldDef, options)` → `{ stop(), setWeather(), setTimeOfDay(), teleport(), state }`. All 12 systems in: procedural skybox + sun/moon/stars with day cycle; weather presets (clear/cloudy/rain/dusk) with rain particles and drifting clouds; seeded heightfield terrain; animated water; instanced foliage by biome; procedural buildings with canvas window textures and enterable interiors (GLB props via GLTFLoader, procedural fallback); districts with labelled placeholder structures; third-person capsule avatar (WASD/arrows, Space jump, Shift run, touch joystick + look-drag + Jump/Interact buttons); NPC dialogue panels with quest accept; quest tracker + rotating collectibles (spark/relic/data); agent companions that follow the avatar; full HUD (quest tracker, collectible counter, compass strip, weather buttons, time slider, info panel). WebGL unavailable → clear fallback message, no crash. Pixel ratio capped at 2. Full API + controls in ENGINE-NOTE.md.

### 2. World data (`worlds/`, `data/`, `assets/glb/`)
- **7 flagship world JSONs**, all `rp1: null`, grounded in the real fabric JSONs (names + scaled positions from real fabric child nodes; transforms recorded per file): SmartCiti.X Holodeck (S10, anchored 39.84645, -86.62161), Cognition.X Campus (S1, anchored 45.48313, 18.57245), Locator.X (S8, anchored 21.09705, 142.69255), Biota.blockchain (anchored -38.71260, -27.24828), Empathic.X (anchored 47.43990, -179.34953), Diagnostic.X (anchored 5.34271, 101.56634), AGI Corp Hub (demo, no coordinates, no fabric file).
- **Totals:** 38 districts, 87 buildings, 31 NPCs, 20 quests, 51 collectibles. 198 `missing_models` entries = 168 distinct GLB refs — exactly the verified unique-path count; every one is shown as a labelled procedural placeholder, never faked.
- **7 verified-local GLBs** in `assets/glb/` (sha256-matched): Stool, Bucket, Crate, Tin, Container, duck, capsule — the only models that exist locally; only the Hub uses them.
- **data/worlds.json** (verbatim 544-world list), **data/anchors.json** (6 anchors), **data/fabrics/** (6 verbatim fabric copies), **data.js** (generated by `tools/gen_data_js.py` — the 544 list + 7 flagship defs as a JS constant, so lobby and player need no fetch and work from `file://`).
- Reproducible builders: `tools/build_worlds.py` (world data + verification pass), `tools/gen_data_js.py` (regenerate `data.js` after any world JSON change). Full grounding table in WORLDS-NOTE.md.

### 3. Lobby + player (`index.html`, `lobby.js`, `player.html`, `player.js`, `site.css`)
- **Lobby:** 7 flagship cards on top ("Playable now"), then the full 544-world index with text search (name/place), biome filter (12 biomes), group filter (city/curated/spotlight), 24/page pagination. Every entry shows its real status; non-flagship entries link to the live WorldForge Earth viewer and show their planned subdomain as text (labelled "does not resolve yet"). Header banner: "Web 3D interpretation — not RP1, not footage."
- **Player:** `player.html?world=<id>` mounts the engine for that flagship, with a world info panel (coordinates, fabric link, counts, missing-models note, sources) and a "Back to lobby" link. Unknown or missing `?world=` shows a friendly error listing the 7 playable worlds — never a blank page.
- Mobile-first responsive CSS (Foundation navy #0b1e3a / gold #c9a227 / teal #0e7c7b); touch controls come from the engine.

## How to open it locally

Recommended (full experience, GLB props load):
```bash
cd ~/workspace/your_files/worlds-3d
python3 -m http.server 8931
# open http://127.0.0.1:8931/ — lobby; click ▶ Play on any flagship
```
`file://` also works for the lobby and the player logic, but Chrome blocks `fetch()` of the GLB files from `file://`, so the Hub's interior props fall back to procedural crates there (the engine handles this gracefully). On any http(s) host the GLBs load normally.

## Known limits (honest)
- **No real-browser render check yet.** WebGL rendering, visuals, touch on a device, and GLB prop loading in a browser are unverified — the engine code paths exist and the fallbacks are verified, but a human (or browser task) must open the player in a real browser and complete one quest before calling this "playable" in public. Playtest checklist: (1) open the lobby, (2) play the Hub (talk to Lobby Host → collect Duck Spark → visit Hub Duck), (3) enter one building interior and exit, (4) switch weather to rain, (5) open on a phone and use the joystick.
- jsdom cannot execute the player module graph (no import-map support) — the player logic was verified with a stubbed engine import; the real import graph was verified separately in Node.
- 168 fabric GLBs are unhosted — all six anchored worlds render with labelled procedural placeholders. Only the Hub has real models.
- RP1 attach is still blocked (needs the public map-service endpoint / Oracle VPS). Nothing here claims to be live on RP1.
- Holodeck's non-Structural districts' halls are real fabric nodes not yet built as buildings this pass; a few Agent nodes (e.g. Locator's Developer Brief Desk, Biota's Communication Agent, Steward seats) were intentionally not made into NPCs.
- The Hub's weather preset is "indoor" — not one of the engine's four presets; the engine degrades gracefully (defaults), but an indoor lighting preset would be a nicer fit in a follow-up.
